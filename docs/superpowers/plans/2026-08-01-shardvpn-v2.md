# shardVPN v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace v1's OpenVPN-and-certificates stack with a Lambda control plane that launches, reports on, and tears down on-demand Tailscale exit nodes on EC2.

**Architecture:** Terraform provisions static scaffolding once (Lambda, IAM, EventBridge schedule, SSM parameters, SNS topic) and is never used at runtime. A single Lambda behind a Function URL handles `up`/`down`/`status` from an HMAC-signed phone request, and the same function handles an hourly `sweep` from EventBridge Scheduler. Cloud-init turns a bare AL2023 arm64 instance into a Tailscale exit node.

**Tech Stack:** Python 3.13 (stdlib + runtime-provided boto3, no third-party deps), Terraform >= 1.13 with `hashicorp/aws ~> 6.57`, Amazon Linux 2023 on arm64, Tailscale, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-01-shardvpn-v2-design.md`

## Global Constraints

- Python **3.13** everywhere — Lambda runtime, CI, local venv. No third-party runtime dependencies; `boto3` comes from the runtime.
- Terraform `>= 1.13`; provider `hashicorp/aws ~> 6.57`.
- **No secret values in Terraform.** `aws_ssm_parameter` stores values in state in plaintext even for `SecureString`. All secret parameters use a placeholder value plus `lifecycle { ignore_changes = [value] }`.
- **No AWS credentials in CI.** Every CI job runs offline.
- **Never log** the signing secret, the OAuth client secret, or a minted auth key.
- Tailnet is always addressed by the `-` alias, never by name.
- Instance tag prefix is `shardvpn:`. Role tag is `shardvpn:role = exit-node`.
- All timestamps are RFC3339 UTC with a `Z` suffix.
- Signing header names: `X-ShardVPN-Timestamp`, `X-ShardVPN-Signature`. Max clock skew **120 seconds**.
- Default region `ca-central-1`. Default instance type `t4g.small`. Default TTL `none`.
- Commit messages: imperative one-liner, e.g. `Adds HMAC request verification.`

```python
"""HMAC request verification for the Function URL. Pure: no AWS, no I/O."""

import base64
import hashlib
import hmac
from collections.abc import Mapping

TIMESTAMP_HEADER = "x-shardvpn-timestamp"
SIGNATURE_HEADER = "x-shardvpn-signature"
MAX_SKEW_SECONDS = 120


class AuthError(Exception):
    """Any verification failure. Deliberately carries no detail — callers must
    not leak which check failed."""


def extract_body(event: dict) -> bytes:
    """Return the request body as the exact bytes the client signed."""
    raw = event.get("body") or ""
    if event.get("isBase64Encoded"):
        return base64.b64decode(raw)
    return raw.encode()


def verify(
    headers: Mapping[str, str],
    raw_body: bytes,
    secret: str,
    now: int,
    max_skew: int = MAX_SKEW_SECONDS,
) -> None:
    """Raise AuthError unless the request carries a fresh, valid signature."""
    lowered = {k.lower(): v for k, v in headers.items()}

    raw_ts = lowered.get(TIMESTAMP_HEADER)
    provided = lowered.get(SIGNATURE_HEADER)
    if not raw_ts or not provided:
        raise AuthError

    try:
        timestamp = int(raw_ts)
    except ValueError:
        raise AuthError from None

    if abs(now - timestamp) > max_skew:
        raise AuthError

    message = f"{timestamp}.".encode() + raw_body
    expected = hmac.new(secret.encode(), message, hashlib.sha256).hexdigest()

    if not hmac.compare_digest(expected, provided):
        raise AuthError
```

```python
"""TTL parsing and expiry. Pure: no AWS, no I/O."""

import re
from datetime import UTC, datetime, timedelta

NEVER = "never"

_TTL_PATTERN = re.compile(r"^(\d+)([mhd])$")
_UNIT_SECONDS = {"m": 60, "h": 3600, "d": 86400}


def rfc3339(dt: datetime) -> str:
    return dt.astimezone(UTC).strftime("%Y-%m-%dT%H:%M:%SZ")


def parse_rfc3339(value: str) -> datetime:
    return datetime.strptime(value, "%Y-%m-%dT%H:%M:%SZ").replace(tzinfo=UTC)


def parse_ttl(ttl: str | None, now: datetime) -> str:
    """Turn a TTL like '48h' into an absolute expiry, or NEVER."""
    if ttl is None or ttl == NEVER:
        return NEVER

    match = _TTL_PATTERN.match(ttl)
    if not match:
        raise ValueError(f"malformed ttl: {ttl!r}")

    amount = int(match.group(1))
    if amount < 1:
        raise ValueError(f"ttl must be positive: {ttl!r}")

    return rfc3339(now + timedelta(seconds=amount * _UNIT_SECONDS[match.group(2)]))


def is_expired(expires_at: str, now: datetime) -> bool:
    if expires_at == NEVER:
        return False
    return parse_rfc3339(expires_at) <= now


def format_duration(seconds: int) -> str:
    """Render a duration compactly: '6m', '2h14m', '1d1h0m'."""
    days, rem = divmod(max(seconds, 0), 86400)
    hours, rem = divmod(rem, 3600)
    minutes = rem // 60
    if days:
        return f"{days}d{hours}h{minutes}m"
    if hours:
        return f"{hours}h{minutes}m"
    return f"{minutes}m"
```

```bash
#!/bin/bash
# shardVPN exit node bootstrap.
# Placeholders ${TS_AUTHKEY} and ${TS_HOSTNAME} are substituted by
# render.py via string.Template before this is passed as EC2 user data.
# Ordering matters: forwarding and GRO must be configured before tailscaled
# starts, or the node advertises itself and silently routes nothing.
set -euo pipefail

exec > >(tee /var/log/shardvpn-init.log) 2>&1

echo "shardvpn: enabling IP forwarding"
cat > /etc/sysctl.d/99-tailscale.conf <<'SYSCTL'
net.ipv4.ip_forward = 1
net.ipv6.conf.all.forwarding = 1
SYSCTL
sysctl --system

echo "shardvpn: installing UDP GRO forwarding unit"
# Tailscale documents persisting this with a networkd-dispatcher hook, which
# does not exist on Amazon Linux 2023. A systemd oneshot ordered before
# tailscaled is the AL2023 equivalent.
cat > /usr/local/sbin/shardvpn-gro <<'GRO'
#!/bin/bash
set -euo pipefail
NETDEV=$(ip -o route get 8.8.8.8 | cut -f 5 -d " ")
ethtool -K "${NETDEV}" rx-udp-gro-forwarding on rx-gro-list off
GRO
chmod 0755 /usr/local/sbin/shardvpn-gro

cat > /etc/systemd/system/shardvpn-gro.service <<'UNIT'
[Unit]
Description=shardVPN UDP GRO forwarding tuning
After=network-online.target
Wants=network-online.target
Before=tailscaled.service

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/local/sbin/shardvpn-gro

[Install]
WantedBy=multi-user.target
UNIT

echo "shardvpn: installing tailscale"
dnf install -y ethtool
dnf config-manager --add-repo \
  https://pkgs.tailscale.com/stable/amazon-linux/2023/tailscale.repo
dnf install -y tailscale

systemctl daemon-reload
systemctl enable --now shardvpn-gro.service

echo "shardvpn: installing logout-on-shutdown unit"
# Removes this ephemeral node from the tailnet immediately on termination.
# Best effort; Tailscale's own ephemeral expiry is the backstop.
cat > /etc/systemd/system/shardvpn-logout.service <<'UNIT'
[Unit]
Description=shardVPN leave tailnet on shutdown
After=tailscaled.service
Requires=tailscaled.service

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/bin/true
ExecStop=/usr/bin/tailscale logout

[Install]
WantedBy=multi-user.target
UNIT

systemctl daemon-reload
systemctl enable --now tailscaled
systemctl enable --now shardvpn-logout.service

echo "shardvpn: joining tailnet"
tailscale up \
  --auth-key="${TS_AUTHKEY}" \
  --advertise-exit-node \
  --ssh \
  --hostname="${TS_HOSTNAME}"

echo "shardvpn: verifying"
if [ "$(cat /proc/sys/net/ipv4/ip_forward)" != "1" ]; then
  echo "shardvpn: FATAL ipv4 forwarding is not enabled" >&2
  exit 1
fi

if ! tailscale status --json | grep -q '"ExitNodeOption": *true'; then
  echo "shardvpn: FATAL node is not advertising as an exit node" >&2
  exit 1
fi

echo "shardvpn: ready"
```

"""Renders the cloud-init script. Pure: no AWS, no I/O beyond reading the
bundled template next to this module."""

from pathlib import Path
from string import Template

_TEMPLATE_PATH = Path(__file__).with_name("userdata.sh")


def render_userdata(authkey: str, hostname: str) -> str:
    """Substitute the auth key and hostname into the bootstrap script.

    Uses safe_substitute so that ordinary shell variables in the script
    (${NETDEV}, ${TS_AUTHKEY} inside heredocs) are not mangled.
    """
    if not authkey:
        raise ValueError("authkey is required")
    if not hostname:
        raise ValueError("hostname is required")

    template = Template(_TEMPLATE_PATH.read_text())
    return template.safe_substitute(TS_AUTHKEY=authkey, TS_HOSTNAME=hostname)
```

```python
"""Tailscale API client. Stdlib only.

The tailnet is always addressed by the '-' alias so the tailnet name never
appears in this public repository.
"""

import json
from urllib.parse import urlencode
from urllib.request import Request, urlopen

API = "https://api.tailscale.com/api/v2"
TIMEOUT = 10


class TailscaleError(Exception):
    """A Tailscale API call failed or returned an unexpected shape."""


def _call(request: Request) -> dict:
    try:
        with urlopen(request, timeout=TIMEOUT) as response:  # noqa: S310
            return json.loads(response.read())
    except Exception as exc:
        raise TailscaleError(f"tailscale api call failed: {type(exc).__name__}") from exc


def get_token(client_id: str, client_secret: str) -> str:
    """Exchange OAuth client credentials for a short-lived access token."""
    data = urlencode({"client_id": client_id, "client_secret": client_secret}).encode()
    request = Request(  # noqa: S310
        f"{API}/oauth/token",
        data=data,
        headers={"Content-Type": "application/x-www-form-urlencoded"},
        method="POST",
    )
    token = _call(request).get("access_token")
    if not token:
        raise TailscaleError("no access_token in oauth response")
    return token


def mint_auth_key(token: str, tag: str, expiry_seconds: int, description: str) -> str:
    """Mint a single-use, pre-authorized, ephemeral auth key for one launch."""
    body = json.dumps(
        {
            "capabilities": {
                "devices": {
                    "create": {
                        "reusable": False,
                        "ephemeral": True,
                        "preauthorized": True,
                        "tags": [tag],
                    }
                }
            },
            "expirySeconds": expiry_seconds,
            "description": description,
        }
    ).encode()

    request = Request(  # noqa: S310
        f"{API}/tailnet/-/keys",
        data=body,
        headers={"Authorization": f"Bearer {token}", "Content-Type": "application/json"},
        method="POST",
    )
    key = _call(request).get("key")
    if not key:
        raise TailscaleError("no key in auth key response")
    return key


def find_device(token: str, hostname: str) -> dict | None:
    """Return the tailnet device with this hostname, or None."""
    request = Request(  # noqa: S310
        f"{API}/tailnet/-/devices",
        headers={"Authorization": f"Bearer {token}"},
        method="GET",
    )
    for device in _call(request).get("devices", []):
        if device.get("hostname") == hostname:
            return device
    return None
```

```python
"""EC2, SSM parameter and CloudWatch operations for exit nodes."""

from datetime import datetime, timedelta

TAG_ROLE = "shardvpn:role"
ROLE_VALUE = "exit-node"
TAG_LAUNCHED = "shardvpn:launched-at"
TAG_EXPIRES = "shardvpn:expires-at"
TAG_ALERTED = "shardvpn:last-idle-alert"
TAG_HOSTNAME = "shardvpn:ts-hostname"

SG_NAME = "shardvpn-exit"
SG_DESCRIPTION = "shardVPN exit node: no ingress, all egress"

AMI_PARAMETER = "/aws/service/ami-amazon-linux-latest/al2023-ami-kernel-default-arm64"

LIVE_STATES = ["pending", "running"]


def resolve_ami(ssm) -> str:
    """Resolve the current AL2023 arm64 AMI in this client's region."""
    return ssm.get_parameter(Name=AMI_PARAMETER)["Parameter"]["Value"]


def ensure_security_group(ec2) -> str:
    """Return the id of the shardvpn security group, creating it if needed.

    The group is created with no ingress rules at all. AWS adds a default
    allow-all egress rule on creation; we authorize egress explicitly so the
    intent is visible rather than inherited.
    """
    existing = ec2.describe_security_groups(
        Filters=[{"Name": "group-name", "Values": [SG_NAME]}]
    )["SecurityGroups"]
    if existing:
        return existing[0]["GroupId"]

    group_id = ec2.create_security_group(GroupName=SG_NAME, Description=SG_DESCRIPTION)[
        "GroupId"
    ]
    ec2.authorize_security_group_egress(
        GroupId=group_id,
        IpPermissions=[{"IpProtocol": "-1", "IpRanges": [{"CidrIp": "0.0.0.0/0"}]}],
    )
    return group_id


def find_node(ec2) -> dict | None:
    """Return the live exit node in this client's region, or None."""
    reservations = ec2.describe_instances(
        Filters=[
            {"Name": f"tag:{TAG_ROLE}", "Values": [ROLE_VALUE]},
            {"Name": "instance-state-name", "Values": LIVE_STATES},
        ]
    )["Reservations"]
    for reservation in reservations:
        for instance in reservation["Instances"]:
            return instance
    return None


def launch(
    ec2,
    *,
    ami: str,
    instance_type: str,
    sg_id: str,
    user_data: str,
    tags: dict[str, str],
    client_token: str,
) -> str:
    """Launch one exit node and return its instance id."""
    response = ec2.run_instances(
        ImageId=ami,
        InstanceType=instance_type,
        MinCount=1,
        MaxCount=1,
        SecurityGroupIds=[sg_id],
        UserData=user_data,
        ClientToken=client_token,
        MetadataOptions={"HttpTokens": "required"},
        TagSpecifications=[
            {
                "ResourceType": "instance",
                "Tags": [{"Key": k, "Value": v} for k, v in tags.items()],
            }
        ],
    )
    return response["Instances"][0]["InstanceId"]


def terminate(ec2, instance_id: str) -> None:
    ec2.terminate_instances(InstanceIds=[instance_id])


def stamp_tag(ec2, instance_id: str, key: str, value: str) -> None:
    ec2.create_tags(Resources=[instance_id], Tags=[{"Key": key, "Value": value}])


def tag_value(instance: dict, key: str) -> str | None:
    for tag in instance.get("Tags", []):
        if tag["Key"] == key:
            return tag["Value"]
    return None


def network_out_bytes(cw, instance_id: str, hours: int, now: datetime) -> int:
    """Total bytes sent by the instance over the trailing window.

    Exit node traffic leaves the instance toward the client, so NetworkOut is
    the usage signal. Basic monitoring gives 5-minute datapoints for free;
    GetMetricStatistics (not GetMetricData) is used because it falls inside
    CloudWatch's free API request tier.
    """
    datapoints = cw.get_metric_statistics(
        Namespace="AWS/EC2",
        MetricName="NetworkOut",
        Dimensions=[{"Name": "InstanceId", "Value": instance_id}],
        StartTime=now - timedelta(hours=hours),
        EndTime=now,
        Period=300,
        Statistics=["Sum"],
    )["Datapoints"]
    return int(sum(point["Sum"] for point in datapoints))
```

```python
"""SSM-backed configuration and the authoritative current-node pointer."""

import json
from dataclasses import dataclass

PARAM_NAMES = {
    "signing_secret": "/shardvpn/signing-secret",
    "ts_client_id": "/shardvpn/tailscale-client-id",
    "ts_client_secret": "/shardvpn/tailscale-client-secret",
    "default_region": "/shardvpn/default-region",
    "default_ttl": "/shardvpn/default-ttl",
    "instance_type": "/shardvpn/instance-type",
    "idle_threshold_bytes": "/shardvpn/idle-threshold-bytes",
    "current_node": "/shardvpn/current-node",
}

EMPTY = "none"


@dataclass(frozen=True)
class Pointer:
    """Which region holds the live node, and which instance it is.

    DescribeInstances is regional, so this is what makes 'is a node already
    up?' answerable without scanning every region on the request path.
    """

    region: str
    instance_id: str


def get_parameter(ssm, name: str, *, decrypt: bool = False) -> str:
    kwargs = {"Name": name}
    if decrypt:
        kwargs["WithDecryption"] = True
    return ssm.get_parameter(**kwargs)["Parameter"]["Value"]


def read_pointer(ssm, name: str) -> Pointer | None:
    try:
        raw = get_parameter(ssm, name)
    except Exception:
        return None
    if not raw or raw == EMPTY:
        return None
    data = json.loads(raw)
    return Pointer(region=data["region"], instance_id=data["instance_id"])


def write_pointer(ssm, name: str, pointer: Pointer | None) -> None:
    value = (
        EMPTY
        if pointer is None
        else json.dumps({"region": pointer.region, "instance_id": pointer.instance_id})
    )
    ssm.put_parameter(Name=name, Value=value, Type="String", Overwrite=True)
```

Catching bare `Exception` in `read_pointer` is deliberate: a missing parameter, a malformed value and a transient SSM error should all degrade to "no known node", after which the watchdog reconciles from the authoritative region scan.

```python
"""Builds the single response document returned by every action."""

from datetime import datetime

from ec2ops import TAG_EXPIRES, TAG_HOSTNAME, TAG_LAUNCHED, tag_value
from ttl import NEVER, format_duration, parse_rfc3339

ABSENT = {
    "state": "absent",
    "region": None,
    "instance_id": None,
    "public_ip": None,
    "tailnet": "unknown",
    "hostname": None,
    "age": None,
    "expires_at": None,
    "idle_for": None,
}


def build(
    instance: dict | None,
    region: str | None,
    ts_online: bool | None,
    idle_seconds: int | None,
    now: datetime,
) -> dict:
    """Describe the current node uniformly, whatever action produced it."""
    if instance is None:
        return dict(ABSENT)

    launched = tag_value(instance, TAG_LAUNCHED)
    expires = tag_value(instance, TAG_EXPIRES)

    if ts_online is None:
        tailnet = "unknown"
    else:
        tailnet = "online" if ts_online else "absent"

    return {
        "state": instance["State"]["Name"],
        "region": region,
        "instance_id": instance["InstanceId"],
        "public_ip": instance.get("PublicIpAddress"),
        "tailnet": tailnet,
        "hostname": tag_value(instance, TAG_HOSTNAME),
        "age": (
            format_duration(int((now - parse_rfc3339(launched)).total_seconds()))
            if launched
            else None
        ),
        "expires_at": None if expires in (None, NEVER) else expires,
        "idle_for": None if idle_seconds is None else format_duration(idle_seconds),
    }
```

```python
"""Lambda entry point: event routing, auth gate, action dispatch."""

import json
import logging
import os
import secrets as pysecrets
import time
from datetime import UTC, datetime

import boto3

import config
import ec2ops
import status as status_module
import tailscale
import ttl as ttl_module
import watchdog
from auth import AuthError, extract_body, verify
from render import render_userdata

log = logging.getLogger()
log.setLevel(logging.INFO)

CONTROL_REGION = os.environ["CONTROL_REGION"]
TS_TAG = os.environ.get("TS_TAG", "tag:shardvpn-exit")
KEY_EXPIRY_SECONDS = 600

FORBIDDEN = {"statusCode": 403, "headers": {"content-type": "application/json"}, "body": "{}"}


def load_secret(ssm, name: str) -> str:
    return config.get_parameter(ssm, name, decrypt=True)


def _respond(code: int, payload: dict) -> dict:
    return {
        "statusCode": code,
        "headers": {"content-type": "application/json"},
        "body": json.dumps(payload),
    }


def lambda_handler(event: dict, context) -> dict:
    # Route on event shape first. A Function URL event always carries
    # requestContext.http; a Scheduler event never does. This is what makes
    # 'sweep' unreachable over HTTP regardless of signature validity.
    if "requestContext" not in event:
        return watchdog.sweep(datetime.now(UTC))

    control_ssm = boto3.client("ssm", region_name=CONTROL_REGION)

    try:
        verify(
            event.get("headers") or {},
            extract_body(event),
            load_secret(control_ssm, config.PARAM_NAMES["signing_secret"]),
            int(time.time()),
        )
    except AuthError:
        return dict(FORBIDDEN)

    try:
        body = json.loads(extract_body(event) or b"{}")
    except json.JSONDecodeError:
        return _respond(400, {"error": "malformed json"})

    action = body.get("action")
    if action == "up":
        return _up(control_ssm, body)
    if action == "down":
        return _down(control_ssm)
    if action == "status":
        return _status(control_ssm)
    return _respond(400, {"error": "unknown action"})


def _describe(control_ssm, pointer, *, check_tailnet: bool = True) -> dict:
    if pointer is None:
        return dict(status_module.ABSENT)

    ec2 = boto3.client("ec2", region_name=pointer.region)
    instance = ec2ops.find_node(ec2)
    if instance is None:
        return dict(status_module.ABSENT)

    online = None
    if check_tailnet:
        hostname = ec2ops.tag_value(instance, ec2ops.TAG_HOSTNAME)
        if hostname:
            token = tailscale.get_token(
                config.get_parameter(
                    control_ssm, config.PARAM_NAMES["ts_client_id"], decrypt=True
                ),
                config.get_parameter(
                    control_ssm, config.PARAM_NAMES["ts_client_secret"], decrypt=True
                ),
            )
            online = tailscale.find_device(token, hostname) is not None

    idle = None
    if instance["State"]["Name"] == "running":
        cw = boto3.client("cloudwatch", region_name=pointer.region)
        now = datetime.now(UTC)
        if ec2ops.network_out_bytes(cw, instance["InstanceId"], 1, now) == 0:
            idle = 3600

    return status_module.build(instance, pointer.region, online, idle, datetime.now(UTC))


def _status(control_ssm) -> dict:
    pointer = config.read_pointer(control_ssm, config.PARAM_NAMES["current_node"])
    return _respond(200, _describe(control_ssm, pointer))


def _down(control_ssm) -> dict:
    pointer = config.read_pointer(control_ssm, config.PARAM_NAMES["current_node"])
    if pointer is None:
        return _respond(200, dict(status_module.ABSENT))

    ec2 = boto3.client("ec2", region_name=pointer.region)
    instance = ec2ops.find_node(ec2)
    if instance is not None:
        ec2ops.terminate(ec2, instance["InstanceId"])

    config.write_pointer(control_ssm, config.PARAM_NAMES["current_node"], None)
    return _respond(200, dict(status_module.ABSENT))


def _up(control_ssm, body: dict) -> dict:
    pointer = config.read_pointer(control_ssm, config.PARAM_NAMES["current_node"])
    if pointer is not None:
        existing = _describe(control_ssm, pointer)
        if existing["state"] != "absent":
            return _respond(200, existing)

    region = body.get("region") or config.get_parameter(
        control_ssm, config.PARAM_NAMES["default_region"]
    )
    default_ttl = config.get_parameter(control_ssm, config.PARAM_NAMES["default_ttl"])
    instance_type = config.get_parameter(control_ssm, config.PARAM_NAMES["instance_type"])

    now = datetime.now(UTC)
    try:
        expires_at = ttl_module.parse_ttl(body.get("ttl") or default_ttl, now)
    except ValueError:
        return _respond(400, {"error": "malformed ttl"})

    suffix = pysecrets.token_hex(2)
    hostname = f"shardvpn-{region}-{suffix}"

    token = tailscale.get_token(
        config.get_parameter(control_ssm, config.PARAM_NAMES["ts_client_id"], decrypt=True),
        config.get_parameter(control_ssm, config.PARAM_NAMES["ts_client_secret"], decrypt=True),
    )
    authkey = tailscale.mint_auth_key(token, TS_TAG, KEY_EXPIRY_SECONDS, f"shardvpn {hostname}")

    regional_ssm = boto3.client("ssm", region_name=region)
    ec2 = boto3.client("ec2", region_name=region)

    instance_id = ec2ops.launch(
        ec2,
        ami=ec2ops.resolve_ami(regional_ssm),
        instance_type=instance_type,
        sg_id=ec2ops.ensure_security_group(ec2),
        user_data=render_userdata(authkey, hostname),
        tags={
            "Name": hostname,
            ec2ops.TAG_ROLE: ec2ops.ROLE_VALUE,
            ec2ops.TAG_LAUNCHED: ttl_module.rfc3339(now),
            ec2ops.TAG_EXPIRES: expires_at,
            ec2ops.TAG_HOSTNAME: hostname,
        },
        client_token=f"shardvpn-{hostname}",
    )

    config.write_pointer(
        control_ssm,
        config.PARAM_NAMES["current_node"],
        config.Pointer(region=region, instance_id=instance_id),
    )

    log.info("launched %s in %s as %s", instance_id, region, hostname)
    return _respond(
        200,
        {
            **status_module.ABSENT,
            "state": "pending",
            "region": region,
            "instance_id": instance_id,
            "hostname": hostname,
            "expires_at": None if expires_at == ttl_module.NEVER else expires_at,
            "age": "0m",
        },
    )
```

```python
"""The hourly sweep: reconcile the pointer, reap expired nodes, notify on idle."""

import logging
import os
from datetime import UTC, datetime, timedelta

import boto3

import config
import ec2ops
from ttl import is_expired, parse_rfc3339

log = logging.getLogger()

CONTROL_REGION = os.environ.get("CONTROL_REGION", "ca-central-1")
TOPIC_ARN = os.environ.get("TOPIC_ARN", "")
IDLE_WINDOW_HOURS = 24
ALERT_INTERVAL = timedelta(hours=24)


def should_alert(
    idle_bytes: int, threshold: int, last_alert: str | None, now: datetime
) -> bool:
    """True when the node looks unused and we have not said so recently."""
    if idle_bytes >= threshold:
        return False
    if last_alert is None:
        return True
    try:
        return now - parse_rfc3339(last_alert) >= ALERT_INTERVAL
    except ValueError:
        # An unparseable stamp should not silence the alert forever.
        return True


def sweep(now: datetime) -> dict:
    """Scan every region for exit nodes; reap, reconcile, and notify."""
    control_ssm = boto3.client("ssm", region_name=CONTROL_REGION)
    sns = boto3.client("sns", region_name=CONTROL_REGION)

    threshold = int(
        config.get_parameter(control_ssm, config.PARAM_NAMES["idle_threshold_bytes"])
    )
    pointer = config.read_pointer(control_ssm, config.PARAM_NAMES["current_node"])

    ec2_control = boto3.client("ec2", region_name=CONTROL_REGION)
    regions = [r["RegionName"] for r in ec2_control.describe_regions()["Regions"]]

    summary: dict = {"checked": 0, "reaped": [], "alerted": [], "orphans": []}
    found: list[tuple[str, dict]] = []

    for region in regions:
        try:
            instance = ec2ops.find_node(boto3.client("ec2", region_name=region))
        except Exception:
            log.warning("region scan failed: %s", region)
            continue
        if instance is not None:
            found.append((region, instance))

    summary["checked"] = len(found)

    for region, instance in found:
        instance_id = instance["InstanceId"]
        ec2 = boto3.client("ec2", region_name=region)

        expires = ec2ops.tag_value(instance, ec2ops.TAG_EXPIRES) or "never"
        if is_expired(expires, now):
            ec2ops.terminate(ec2, instance_id)
            summary["reaped"].append(instance_id)
            _publish(sns, f"shardvpn: reaped {instance_id} in {region} (expired {expires})")
            continue

        if pointer is None or pointer.instance_id != instance_id:
            summary["orphans"].append(instance_id)
            _publish(
                sns,
                f"shardvpn: found untracked node {instance_id} in {region}. "
                "If you did not launch this, rotate the signing secret.",
            )

        if instance["State"]["Name"] != "running":
            continue

        cw = boto3.client("cloudwatch", region_name=region)
        idle_bytes = ec2ops.network_out_bytes(cw, instance_id, IDLE_WINDOW_HOURS, now)
        last_alert = ec2ops.tag_value(instance, ec2ops.TAG_ALERTED)

        if should_alert(idle_bytes, threshold, last_alert, now):
            launched = ec2ops.tag_value(instance, ec2ops.TAG_LAUNCHED) or "unknown"
            _publish(
                sns,
                f"shardvpn: node {instance_id} in {region} has been idle for "
                f"{IDLE_WINDOW_HOURS}h (launched {launched}, {idle_bytes} bytes out). "
                "Send {\"action\":\"down\"} if you are finished with it.",
            )
            ec2ops.stamp_tag(
                ec2, instance_id, ec2ops.TAG_ALERTED, now.strftime("%Y-%m-%dT%H:%M:%SZ")
            )
            summary["alerted"].append(instance_id)

    # Reconcile: the pointer is a cache, the region scan is the truth.
    if found:
        region, instance = found[0]
        if pointer is None or pointer.instance_id != instance["InstanceId"]:
            config.write_pointer(
                control_ssm,
                config.PARAM_NAMES["current_node"],
                config.Pointer(region=region, instance_id=instance["InstanceId"]),
            )
    elif pointer is not None:
        config.write_pointer(control_ssm, config.PARAM_NAMES["current_node"], None)

    log.info("sweep complete: %s", summary)
    return summary


def _publish(sns, message: str) -> None:
    if not TOPIC_ARN:
        return
    sns.publish(TopicArn=TOPIC_ARN, Subject="shardvpn", Message=message)


def _now() -> datetime:
    return datetime.now(UTC)
```

//
// First run prompts for the Function URL and signing secret and stores both in
// the iOS keychain. Subsequent runs sign and send a request.
//

const KEY_URL = "shardvpn.url";
const KEY_SECRET = "shardvpn.secret";

// --- vendored HMAC-SHA256 (no dependencies, no network) ---------------------

function sha256(bytes) {
  const K = [
    0x428a2f98, 0x71374491, 0xb5c0fbcf, 0xe9b5dba5, 0x3956c25b, 0x59f111f1,
    0x923f82a4, 0xab1c5ed5, 0xd807aa98, 0x12835b01, 0x243185be, 0x550c7dc3,
    0x72be5d74, 0x80deb1fe, 0x9bdc06a7, 0xc19bf174, 0xe49b69c1, 0xefbe4786,
    0x0fc19dc6, 0x240ca1cc, 0x2de92c6f, 0x4a7484aa, 0x5cb0a9dc, 0x76f988da,
    0x983e5152, 0xa831c66d, 0xb00327c8, 0xbf597fc7, 0xc6e00bf3, 0xd5a79147,
    0x06ca6351, 0x14292967, 0x27b70a85, 0x2e1b2138, 0x4d2c6dfc, 0x53380d13,
    0x650a7354, 0x766a0abb, 0x81c2c92e, 0x92722c85, 0xa2bfe8a1, 0xa81a664b,
    0xc24b8b70, 0xc76c51a3, 0xd192e819, 0xd6990624, 0xf40e3585, 0x106aa070,
    0x19a4c116, 0x1e376c08, 0x2748774c, 0x34b0bcb5, 0x391c0cb3, 0x4ed8aa4a,
    0x5b9cca4f, 0x682e6ff3, 0x748f82ee, 0x78a5636f, 0x84c87814, 0x8cc70208,
    0x90befffa, 0xa4506ceb, 0xbef9a3f7, 0xc67178f2,
  ];
  const H = [
    0x6a09e667, 0xbb67ae85, 0x3c6ef372, 0xa54ff53a,
    0x510e527f, 0x9b05688c, 0x1f83d9ab, 0x5be0cd19,
  ];

  const rotr = (x, n) => (x >>> n) | (x << (32 - n));
  const len = bytes.length;
  const withPad = [...bytes, 0x80];
  while (withPad.length % 64 !== 56) withPad.push(0);
  const bits = len * 8;
  for (let i = 7; i >= 0; i--) withPad.push((bits / Math.pow(2, i * 8)) & 0xff);

  const h = H.slice();
  for (let chunk = 0; chunk < withPad.length; chunk += 64) {
    const w = new Array(64);
    for (let i = 0; i < 16; i++) {
      const j = chunk + i * 4;
      w[i] =
        (withPad[j] << 24) | (withPad[j + 1] << 16) | (withPad[j + 2] << 8) | withPad[j + 3];
    }
    for (let i = 16; i < 64; i++) {
      const s0 = rotr(w[i - 15], 7) ^ rotr(w[i - 15], 18) ^ (w[i - 15] >>> 3);
      const s1 = rotr(w[i - 2], 17) ^ rotr(w[i - 2], 19) ^ (w[i - 2] >>> 10);
      w[i] = (w[i - 16] + s0 + w[i - 7] + s1) | 0;
    }
    let [a, b, c, d, e, f, g, hh] = h;
    for (let i = 0; i < 64; i++) {
      const S1 = rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25);
      const ch = (e & f) ^ (~e & g);
      const t1 = (hh + S1 + ch + K[i] + w[i]) | 0;
      const S0 = rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22);
      const maj = (a & b) ^ (a & c) ^ (b & c);
      const t2 = (S0 + maj) | 0;
      hh = g; g = f; f = e; e = (d + t1) | 0;
      d = c; c = b; b = a; a = (t1 + t2) | 0;
    }
    const next = [a, b, c, d, e, f, g, hh];
    for (let i = 0; i < 8; i++) h[i] = (h[i] + next[i]) | 0;
  }
  const out = [];
  for (const v of h) out.push((v >>> 24) & 0xff, (v >>> 16) & 0xff, (v >>> 8) & 0xff, v & 0xff);
  return out;
}

function hmacSha256Hex(keyStr, messageStr) {
  const enc = (s) => Array.from(new TextEncoder().encode(s));
  let key = enc(keyStr);
  if (key.length > 64) key = sha256(key);
  while (key.length < 64) key.push(0);

  const inner = key.map((b) => b ^ 0x36).concat(enc(messageStr));
  const outer = key.map((b) => b ^ 0x5c).concat(sha256(inner));
  return sha256(outer)
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");
}

async function prompt(title, message) {

  alert.addAction("Save");

}

    Keychain.set(KEY_URL, await prompt("shardVPN", "Lambda Function URL"));
  }
  if (!Keychain.contains(KEY_SECRET)) {
    Keychain.set(KEY_SECRET, await prompt("shardVPN", "Signing secret"));
  }

}

async function main() {
  const { url, secret } = await config();

  let action = args.shortcutParameter || args.queryParameters?.action;

```markdown
# shardVPN

On-demand Tailscale exit node on EC2, triggered from a phone. v2 rewrite;
v1 (Terraform 0.11 + OpenVPN + a certificate authority) is dead and lives only
in git history on `master`. Do not use it as a reference.

## Architecture

Terraform provisions static scaffolding once and is not used at runtime. A
single Python 3.13 Lambda is the whole control plane: a Function URL serves
`up`/`down`/`status` from an HMAC-signed phone request, and EventBridge
Scheduler invokes the same function hourly with `sweep`. Cloud-init turns a
bare AL2023 arm64 instance into a Tailscale exit node with no inbound ports.

## Layout

- `lambda/` — one module per responsibility. `auth`, `ttl`, `status` and
  `render` are pure and fully unit-tested; `config`, `ec2ops`, `tailscale` and
  `watchdog` touch the outside world.
- `lambda/userdata.sh` — cloud-init. A real shell script under `shellcheck`,
  not a template; `render.py` fills `${TS_AUTHKEY}` and `${TS_HOSTNAME}` via
  `string.Template`.
- `terraform/` — single root module.
- `docs/ios/shardvpn.js` — Scriptable client.
- `docs/superpowers/specs/2026-08-01-shardvpn-v2-design.md` — the design and
  the reasoning behind every tradeoff.

## Running and verifying

```bash
python3.13 -m venv .venv && .venv/bin/pip install pytest boto3 ruff
.venv/bin/ruff check . && .venv/bin/pytest -v
cd terraform && terraform init -backend=false && terraform validate
shellcheck lambda/userdata.sh
```

Tests are offline: `botocore.stub.Stubber` for AWS, `urlopen` patched for
Tailscale. There is no integration test — the real check is the end-to-end run
in the plan (`curl ifconfig.me` through the node from two devices at once).

## Settled

- Tailscale, not OpenVPN. No per-trip key distribution.
- Lambda control plane; nothing runs between trips.
- HMAC + timestamp auth on a Function URL with `authorization_type = NONE`.
  120s skew window. Replay inside that window is accepted, since all actions
  are idempotent.
- Idempotency is the SSM pointer `/shardvpn/current-node` plus reserved
  concurrency 1. `DescribeInstances` is regional, so a pointer is required.
- TTL defaults to `none`. Forgotten nodes are surfaced by a 24h idle SNS
  email, not killed.
- Python 3.13, no third-party deps, runtime-provided boto3, no build step.
  Tradeoff recorded in spec §12.
- OAuth client gets `auth_keys` + `devices:core:read` only. The node removes
  itself from the tailnet via a shutdown-ordered `tailscale logout`.
- IPv6-only rejected: default VPCs have no IPv6 CIDR.

## Open

- Idle threshold in `/shardvpn/idle-threshold-bytes` is a guess until measured
  during a real run.
- Whether Scriptable exposes a native crypto primitive (a pure-JS HMAC is
  vendored on the assumption it does not).
- Whether Scriptable Keychain values sync to iCloud.
- Whether `kms:Decrypt` must be granted explicitly for `alias/aws/ssm`.

## Gotchas

- Never let a secret value reach Terraform state. `aws_ssm_parameter` stores
  values in plaintext in state even for `SecureString`; secret parameters use
  a placeholder plus `ignore_changes = [value]`.
- Tailscale's UDP GRO persistence recipe uses `networkd-dispatcher`, which
  does not exist on AL2023. We use a systemd oneshot ordered before
  `tailscaled`. Getting this wrong fails silently — the node advertises itself
  and routes nothing.
- Sign over raw request bytes. Function URLs base64-encode the body when
  `isBase64Encoded` is set.
- Address the tailnet as `-`, never by name; this repo is public.

- [ ] **Step 5: Measure the idle baseline and set the threshold**

```bash

  --dimensions Name=InstanceId,Value=<id> \
  --start-time <1h ago> --end-time <now> --period 300 --statistics Sum
